# CASHME — Requerimentos de Intimação

Canal público de versões do aplicativo de requerimentos de intimação da Valença & Associados.

Os downloads serão disponibilizados na seção **Releases**, após homologação.
O aplicativo também informa na tela **Início** quando uma nova versão estável está disponível.

Este repositório não contém o código-fonte, documentos de clientes ou credenciais.

Ainda não há uma versão homologada para download.
